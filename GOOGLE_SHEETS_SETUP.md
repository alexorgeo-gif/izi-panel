# Подключение заявок к Google Sheets

Google-таблица уже создана. Для автоматической записи нужна одноразовая публикация защищённого Apps Script и две переменные Netlify.

## 1. Создать веб-приложение Apps Script

1. Откройте существующую Google-таблицу [`Open Village 2026 — база лидов`](https://docs.google.com/spreadsheets/d/1bkrkd-CnxaTd7gk2uSbMnQUsgXJ7uU3JfVHFRySbNLE/edit). Новую таблицу создавать не нужно: её ID уже указан в `google-apps-script/Code.gs`.
2. Выберите **Расширения → Apps Script**.
3. Замените содержимое `Code.gs` кодом из `google-apps-script/Code.gs` этого проекта.
4. Откройте **Настройки проекта → Свойства скрипта** и добавьте:
   - `WEBHOOK_SECRET` — случайная строка длиной не менее 32 символов.
5. Выберите **Развернуть → Новое развертывание → Веб-приложение**:
   - выполнять от вашего имени;
   - доступ: любой пользователь.
6. Скопируйте URL развертывания вида `https://script.google.com/macros/s/.../exec`.

Не добавляйте URL и секрет в GitHub.

## 2. Настроить Netlify

В настройках сайта Netlify добавьте переменные окружения с доступом для Functions:

- `GOOGLE_SHEETS_WEBHOOK_URL` — URL веб-приложения Apps Script;
- `GOOGLE_SHEETS_WEBHOOK_SECRET` — тот же секрет из свойств скрипта.

После добавления переменных запустите новое production-развертывание.

## 3. Проверить

1. Отправьте тестовую заявку через опубликованный сайт.
2. Убедитесь, что заявка осталась в Netlify Forms.
3. Проверьте новую строку на листе `Лиды`.
4. Проверьте сегмент, статус `Новый`, приоритет `Не определён` и UTM-поля.
5. После успешного теста удалите строку `TEMPLATE`.

Netlify Forms остаётся резервным источником: если синхронизация временно не сработает, заявка не потеряется и останется в Netlify.
