# IZI PANEL

Брендовый лендинг декоративных панелей с рабочей воронкой Open Village.

## Что внутри

- адаптивный одностраничный сайт в Brand System №1;
- сегментация частных заказчиков, дизайнеров, строителей и дилеров;
- трёхшаговая форма квалификации;
- сбор заявок через Netlify Forms;
- серверная синхронизация подтверждённых заявок с Google Sheets;
- скрытая маркировка источника `open-village-2026`;
- заготовки под реальные цены, каталог, контакты и QR-код.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка для Netlify

Netlify использует параметры из `netlify.toml` и команду:

```bash
npm run build:netlify
```

После публикации проверьте три тестовые заявки в разделе Forms панели Netlify.

## Google Sheets

Таблица лидов создаётся отдельно от сайта. Netlify Forms остаётся резервным хранилищем, а подтверждённые заявки передаются в Google Sheets серверной функцией. Одноразовая настройка описана в `GOOGLE_SHEETS_SETUP.md`.

## Бренд и форма

Латинское написание `IZI PANEL`, логотипы, бежевая палитра и Commissioner подтверждены владельцем. Форма сохраняет имя `open-village-lead`, источник `open-village-2026`, UTM, квалификационные поля и доставку через Netlify Forms. Коммерческие характеристики и конкретные позиции подтверждаются отдельно.
